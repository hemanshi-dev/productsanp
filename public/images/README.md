# Public Images Folder

This folder contains static images that are served directly by the web server.

**Usage:**
- Images here can be referenced in HTML/CSS as: `/images/filename.jpg`
- Example: `<img src="/images/logo.png" alt="Logo" />`
- These images are copied to the build output as-is

**Best for:**
- Logos, favicons
- Large images that don't need optimization
- Images referenced in CSS backgrounds
